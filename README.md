# Clinical LLM Evaluation & Safety Portfolio

**Michael Dev, MBBS**

Independent portfolio evaluating the clinical accuracy, reasoning, safety, and reliability of large language model (LLM) outputs in healthcare.

## Objective

This project demonstrates structured evaluation of AI-generated medical responses using clinical reasoning, evidence verification, and safety-focused assessment.

## Evaluation Framework

Model outputs are evaluated across seven domains:

- Factual Accuracy
- Clinical Reasoning
- Completeness
- Patient Safety
- Guideline Concordance
- Communication Quality
- Hallucination / Unsupported Claims

Each domain is scored from **1–5**, with identified errors additionally classified by clinical severity.

## Evaluation Methods

The portfolio includes:

- Rubric-based clinical evaluation
- Medical fact-checking
- Guideline verification
- Pairwise (A/B) response evaluation
- Hallucination detection
- Uncertainty and calibration assessment
- Subgroup bias and equity evaluation
- Clinical AI red-teaming
